# Plugin Configuration & Compatibility Guide

This guide details how to configure `@blockvibe/payload-visual-builder` and ensure seamless operation alongside core Payload 3.0 plugins.

---

## 1. Plugin Options Reference

```ts
import { visualBuilderPlugin } from '@blockvibe/payload-visual-builder'

export default buildConfig({
  plugins: [
    visualBuilderPlugin({
      enabled: true,
      collections: ['pages'],
    }),
  ],
})
```

| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `enabled` | `boolean` | `true` | Toggle visual builder active state. |
| `collections` | `string[]` | `['pages']` | Collections enabled for visual editing. |

---

## 2. Multi-Tenant Plugin Compatibility (`@payloadcms/plugin-multi-tenant`)

When used with Payload's multi-tenant plugin:
- The visual builder respects the current tenant context (`doc.tenant`).
- Revalidation calls pass tenant-specific URLs (`revalidatePath("/[tenant]/[slug]")`).

---

## 3. S3 Cloud Storage Compatibility (`@payloadcms/storage-s3`)

Media pickers integrated in the visual builder render media URLs generated by Payload's S3 plugin adapter, ensuring direct compatibility with GCS and AWS S3 object buckets.
